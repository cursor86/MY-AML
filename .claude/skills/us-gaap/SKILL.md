# US GAAP (ASC)

Orientation summaries of 33 ASC topics, one file per topic in this directory
(`asc-<topic>.md`). Each file covers: what it addresses, key requirements,
key disclosures, and key differences from IFRS.

**Read the relevant `asc-<topic>.md` file directly for the standard in
question.** Topics covered: 205, 230, 250, 260, 270, 280, 310, 320, 326,
330, 350, 360, 410, 450, 470, 480, 505, 606, 715, 718, 740, 805, 810, 815,
820, 830, 842, 850, 855, 932, 944, 958, 985.

**Important — these are orientation summaries, not the authoritative
codification text.** Each file carries this note from upstream:

> Verification required. This is an orientation summary, not the
> authoritative text. Standards are amended, and effective dates differ by
> jurisdiction. Before using this for any decision-grade output (financial
> statements, audit conclusions, filings), verify against the current
> standard from the issuing body (FASB) and state in your output which
> version you relied on.

This is meaningfully less rigorous than the paragraph-cited `ifrs` skill in
this same directory — treat a finding grounded here as directional, and
say so, rather than citing it as if it were codification text.

## When comparing to IFRS

Cross-reference the `ifrs` skill's `standards-reference.md` for the IFRS
side of the comparison (e.g. IFRS 15 vs ASC 606, IFRS 16 vs ASC 842) --
both are converged standards with the same five-step / recognition model
in most cases, but the "Key Differences from IFRS" section in each
`asc-*.md` file flags where they diverge.
