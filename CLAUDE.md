# Web Engineering Directives
- **Architecture**: Always prioritize modern component design (Functional, hooks-based) and semantic HTML5. Use Tailwind CSS for all layout stylings.
- **Token Constraints**: Output concise, modified diff-blocks only. Do not rewrite static components or surrounding template files. 
- **Design Guidelines**: Enforce strict responsive breakpoints (`sm:`, `md:`, `lg:`), clean element padding, logical color accessibility (WCAG compliant), and smooth CSS transitions.
